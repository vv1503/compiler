Генерация лексера и парсера (Python 3) из MiniR.g4
===================================================

Требуется Java 8+ и JAR ANTLR (в проекте: app/tools/antlr-4.9.3-complete.jar).

Из каталога app/grammar:

  java -jar ../tools/antlr-4.9.3-complete.jar -Dlanguage=Python3 -visitor -listener -o ../antlr_generated MiniR.g4

Версия antlr4-python3-runtime в requirements.txt должна совпадать с версией ANTLR Tool (4.9.3).

Примечание: ANTLR 4.13+ требует Java 11+; при Java 8 используйте antlr-4.9.3-complete.jar.
