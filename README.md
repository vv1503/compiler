## Лабораторная работа №5 - абстрактное синтаксическое дерево и семантический анализ

### Вариант задания

**Вариант:** цикл for на языке R; построение **AST**.

Корректный пример:

```text
for (i in 1:10) {
    print(i)
};
```

### Цель работы

Изучить назначение семантического анализатора в структуре компилятора, освоить построение AST для заданной грамматики и реализовать проверку контекстно-зависимых условий (уникальность имён, типы, диапазоны, использование объявленных идентификаторов в `print`).

### Что реализовано в программе

- Синтаксический разбор и построение AST (`app/syntax_parser.py`, узлы в `app/ast_nodes.py`).
- Семантические проверки (правила 1–4) в процессе разбора.
- Вывод AST на вкладке **AST**: текстовое дерево и JSON.
- Вывод ошибок на вкладке **Ошибки**: *Неверный фрагмент* | *Местоположение* | *Описание*; подсветка фрагмента в редакторе по щелчку.
- Строка **«Общее количество ошибок: N»** под таблицей ошибок.
- Графическое окно **«Показать AST»** (кнопка внизу вкладки **AST**).

### Структура AST

Используются узлы:

- `ProgramNode` — корень, список операторов верхнего уровня.
- `ConstDeclNode`, `VarDeclNode` — объявления с именем, модификаторами, типом и литералом-значением.
- `ForStmtNode` — цикл `for`, переменная и диапазон; дочерние узлы — границы (`IntLiteralNode`) и тело.
- `PrintStmtNode` — вызов `print`, дочерний `IdentifierNode`.
- `IntLiteralNode`, `FloatLiteralNode` — литералы.
- `IdentifierNode` — использование имени.
- `SimpleTypeNode` — явный тип `int` / `float` при аннотации.

### Формат вывода программы

**Вкладка `AST`:**

- печатается текстовое дерево AST (блок «AST (Дерево)»);
- JSON-представление;
- внизу вкладки - кнопка **`Показать AST`** (графическое дерево в отдельном окне, если ошибок нет).

**Вкладка `Ошибки`:**

- таблица: *Неверный фрагмент* | *Местоположение* | *Описание*;
- внизу: **Общее количество ошибок: N**.

### Графическая визуализация AST

Отдельное окно открывается по кнопке **`Показать AST`** на вкладке **`AST`**. Кнопка **«Показать AST»** сама выполняет лексический и синтаксический/семантический разбор текста; окно графа открывается только если **ошибок нет**.

Использованные графические средства:

- `PyQt6.QtWidgets.QGraphicsView` + `QGraphicsScene` - холст;
- `QGraphicsRectItem` - прямоугольники узлов;
- `QGraphicsTextItem` - подписи (тип узла и атрибуты в формате `key=value`);
- `QGraphicsLineItem` - рёбра «родитель -> потомок».
